**lab_1_version_control**  
 **Тема**  
Робота з версійним контролем (Git)  
   
**Мета роботи**  
- Ознайомлення з основами роботи з системами контролю версій.  
- Опанування базових навичок використання Git для роботи з репозиторіями.  
- Реєстрація на популярних сервісах для роботи з версійним контролем: GitHub, GitLab, Bitbucket.  
- Створення репозиторію, додавання проєкту та надання публічного доступу.
